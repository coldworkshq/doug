## Test-for-intent strategy

Dict rows in, labels out. No githubkit mocks in `test_convergence.py`; the store helper is tested against SQLite rows written by `save_review`.

| Test pins | Why it must fail when logic changes |
|---|---|
| Absence is not evidence | prior finding absent, both indexes present and equal → `persisted`, never `resolved` |
| An absent key is not an empty set | `prior_read["hunks"]` lacks the file → `unknown(file-uncovered)`; `hunks=None` on either side → `unknown(no-hunk-index)`, counted in `unknown` |
| By-construction requires strict multiset equality | prior ⊂ later, or one hash survives → `unknown(not-reconfirmed)` |
| Left-diff never resolves | every prior hash absent and file absent from later index → `unknown(left-diff)` (covers pure rename: `review.py:108` drops nothing for `+0/-0`) |
| Hunk-edited | every prior hash absent, file present with ≥1 hunk → `resolved(basis=hunk-edited)` |
| Pair delta | identical indexes → `unchanged`; any other file differs → `changed-elsewhere`, still `persisted` |
| Hash ignores `@@` numbers and context | same `+`/`-` lines under shifted `@@` and different context → equal hashes |
| Index over the SENT slice only | a file past `DIFF_BUDGET` is absent from the index; `file_cut` absent |
| The worker never imports convergence | importer list is exactly `["store.py"]`; purity import set unchanged |
| Replay renders the same section | `_replay_recorded` and the fresh path produce byte-identical `### Since` text from one ledger |
| Banned strings | `check_run.py` source contains none of `failure\|action_required\|success\|cancelled\|timed_out\|stale`; summary contains no "miss rate", no ratio |
| Eval and product compute the same function | `index_from_git` and `reader.hunk_index` agree on one unified diff fed both ways; the 43-unit split matches Phase 0 |
