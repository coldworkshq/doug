# Design Lock: Walked Out — evidence-gated `resolved` in the convergence lane

**Locked 2026-08-19.** Produced by a design debate (Architect / Principal Engineer / PM; Chief Architect adjudicating; three-lens red team). Ground truth: [ground-truth.md](ground-truth.md), anchored on `origin/main @ 7905735`. Debate record with the data that decided it: [debate-record.md](debate-record.md). Measurement script: [hunk_multiplicity.py](hunk_multiplicity.py).

This lock is the ruling on bar 1 of `outcome-loop/convergence-eval-results.md`: the failure is answered by a redesign of rule 5, not a repair of the sample or the rules. Bar 1 stays FAILED as recorded.

## Converged design

**What Doug claims, in one sentence.** Doug stops carrying a finding forward only when it has deterministic evidence; it carries a finding forward by construction when the cited file's diff is byte-unchanged; it abstains everywhere else; and it prints, on every check run, how many of its own earlier findings on unchanged code its reader did not mention again.

**Identity.** A finding's convergence identity is `(pattern, file, H)` where `H` is the multiset of content hashes of the unified hunks of `file` in the patch the reader was sent. A hunk hash is `sha256` over the hunk's `+` and `-` lines only (no `@@` header numbers, no context lines). `H` is computed by a pure function over the assembled diff text, beside `reader.coverage`, over the SENT slice only, so the prior read's coverage is baked in. Doug does not know which hunk a finding is about; this is file-delta identity at hunk grain, not a per-finding span.

**Storage.** `reads.hunks` — one nullable JSON column (`{path: [sha256, …]}`), migration 12 (additive, ADR-0011), written in `save_review` in the same transaction as the `reads` row, reader tier only. Nothing is added to `findings`, `verdicts.raw`, or the reader `SCHEMA`. `PROMPT_HASH` does not move; ADR-0012 stays closed.

**Classifier.** `convergence.classify` stays pure (imports unchanged; `test_convergence_is_pure` unchanged) and gains the two reads' hunk indexes as input rows. Rules 1–4 and their order are unchanged. Rule 5 is replaced. For a prior identity absent from the later read and not abstained by rules 2–4:

| Condition | State |
|---|---|
| `file` absent from the PRIOR index (prior read did not send it, or the path is model text that was never in a patch) | `unknown(file-uncovered)` — rule 3 extended to the prior side; an absent key is not an empty set |
| either read has no index (pre-migration row; old revision) | `unknown(no-hunk-index)` |
| prior multiset == later multiset | `persisted(basis=by-construction)`, with `pair_delta ∈ {unchanged, changed-elsewhere}` from whether any file's multiset differs between the reads |
| every prior hash absent; `file` present in the later patch with ≥1 hunk | `resolved(basis=hunk-edited)` |
| every prior hash absent; `file` absent from the later patch | `unknown(left-diff)` — covers file reverted to base, pure rename, and hunks absorbed into base |
| some prior hashes survive, or prior ⊂ later | `unknown(not-reconfirmed)` — strict equality for by-construction; an added hunk in the same file may be the fix attempt |

`new` findings carry `code_changed: bool` from the same indexes. Rule 4 keeps its output `unknown(settled)` in v1. `ratio` keeps its definition; `unknown` never enters it.

**Computation and surface.** `store.convergence_for(verdict_id)` is the single importer of `convergence` (as `test_convergence.py:335-357` pre-declared): id-keyed; prior = the preceding reader-tier verdict for the same `(installation_id, github_repo_id, pr_number)` under the eval's ordering key `(scored_at, id)` (`convergence_eval.py:80-87`) — product and eval pair by one key or they can pair differently under concurrent workers; loads both sides' `findings` and `reads`; calls `classify`; wrapped so a DB failure after a paid read degrades to a weight-0 notice and never kills the job or the check run. The worker calls it after `save_review` and in `_replay_recorded`; it never imports `convergence`. The check run gains one `### Since <sha12>` section in the summary: first line is the per-PR silence count with its denominator ("of N earlier findings on files unchanged since <sha12>, M were not mentioned by this read"), then a provenance line ("Compared with Doug's last diff read at <sha12>; the reader's silence is not evidence"), then the states in PM's order and words. No ratio, no rate, no annotations, no `details_url` change, conclusion stays `neutral`.

**Evaluation.** The eval script computes each side's index with a reusable `hunk_index(repo, sha, path)` emulating the three-dot base as `git merge-base origin/main <head>` (assumptions stated in the label: main append-only; PR ancestors reach main only through this PR's squash) and applies the table above; the file-grain `git diff --name-only from to` result is reported beside it as a proxy. Bars are re-pre-registered in `convergence-design.md` before any labelling (see product-spec and build-plan).

**Publication.** The silence rate is defined by a sibling pre-registration in `convergence-design.md` now (numerator: earlier findings on files unchanged between consecutive reader reads that the later read did not mention; denominator: all earlier findings on files unchanged between those reads; population named in the sentence). It goes on the scoreboard in v1.1, web-validator-first. The per-PR count ships in v1.

## Resolved tensions

- **Tension:** where spans come from — model-emitted `line_start/line_end` in `SCHEMA` (A) vs a deterministic hunk-hash index over the patches already fetched (B) vs paid citations (C). **Call:** B in v1; A is a measured upgrade (trigger: published prospective abstention rate after ≥N pairs, a pre-registered span-validation design against sent hunks, and a new ADR superseding ADR-0012's SCHEMA clause — ADR-0014 or later, 0013 is taken); C stays out. **Killed:** A in v1. **Why:** on the 265 resolved findings B answers 195 (160 by-construction, 35 resolved) and abstains on 70; today all 265 are an unevidenced `resolved`. A moves `PROMPT_HASH`, splits the probe pin test, cannot be validated on any historical row, and a hallucinated span is a silent false `persisted` — worse in a loop than an abstention. B's index is the validator A would need. **Cost:** B abstains on 67% of file-touched findings; `resolved` comes almost only from single-hunk files (33/35).
- **Tension:** what "by construction" may claim when other code in the PR changed. **Call:** one state, two `pair_delta` values, two sentences; both `persisted` for the ratio, both `open` for guidance. **Killed:** routing `changed-elsewhere` to the human (it is the majority case — real still-present findings the reader dropped, 26/43). **Why:** Bar B measures exactly this bet; the fix-elsewhere class (#75) is the pre-declared ≤1/26.
- **Tension:** settle disproof as `resolved`, as its own `disproved` state, or as `unknown(settled)`. **Call:** `unknown(settled)` stays in v1; `disproved` (terminal, outside the ratio, closed for guidance) is defined with the guidance string in v1.1. **Killed:** folding into `resolved` (changes what bar 3 and the ratio mean). **Why:** n=0 in 118 pairs; renaming a never-observed state buys nothing in v1.
- **Tension:** persistence — `reads.hunks` column vs a `read_files` table. **Call:** the column. **Killed:** the table (no per-file query exists). **Why:** the index is read whole; one additive column, one migration.
- **Tension:** who imports `convergence` — `store.py` vs the worker. **Call:** `store.py` only. **Killed:** worker import. **Why:** the structural test pre-declared `store.py` as the only future importer and said the worker stays forbidden; reversing that silently is the failure mode the test exists to catch.
- **Tension:** the `left-diff` case as `resolved` (with base-advance and rename guards) vs `unknown`. **Call:** `unknown(left-diff)`, unconditionally. **Killed:** `resolved(basis=left-diff)`, `reads.base_sha`, the rename map, `unknown(base-advanced)`, and the vNext compare-API mitigation — all three round-1 amendments collapsed by the scope red team. **Why:** the branch is worth 2/35 of `resolved` in the population and 1/7 of the spike's sample resolves, and it cost a migration column, a rename map, two states and a network mitigation; a pure rename (no patch, not in `files_dropped`) would have read as `resolved`.
- **Tension:** what the eval validates. **Call:** the eval emulates the product's function per side (three-dot base) and labels itself `hunk-emulated`; file grain is reported as a proxy. **Killed:** validating the shipped rule with `git diff --name-only from to` alone (a different function: merge-from-main counts as touched in git and not in patches). **Why:** a file-grain pass would otherwise be read as a pass of the shipped rule.
- **Tension:** lead with the feature or the number. **Call:** the per-PR silence count is the first line of the section; the silence-rate pre-registration is written now. **Killed:** sequencing the number behind the reland-labeler fix and prereg v10 by default. **Why:** the three-state feature is copyable in a sprint by any bot that posts review threads (GitHub computes per-line `outdated`); the number is the part incumbents structurally will not print.

## Supersessions

- Round-1 amendments A1 (`reads.base_sha`, `base_advanced`), A2 (`renamed` map), A3 (`unknown(base-advanced)`) were adopted, then superseded at red-team by the `left-diff → unknown` cut. The rename and base-absorption hazards they addressed are covered by the abstention.
- Round-1 R3 (`disproved` in v1) superseded: deferred to v1.1 with the guidance string.
- Round-1 R7 (`halt_guidance` frozen now) superseded: v1.1, with the honesty mitigations below folded into its contract.
- Round-1 R10 ("freeze the payload now by addendum") superseded: "before first consumer", per ground truth.
- PM red-line "v1 must answer per-finding on a partial-file edit or it is a disclosure" superseded by data: v1 answers on a declared, published fraction (74% of the population; 100% of untouched files and single-hunk files).
- **Andrew's ruling 1 (2026-08-18), letter only:** "findings must carry line/hunk spans" is honored in substance (identity is hunk-hashed) and not in letter (no per-finding span). **Andrew's 2026-08-20 ruling: decide by measurement.** A pre-registered verification pass ([span-verification.md](span-verification.md)) grades model hunk-attribution for stability and correctness on the eval corpus; ADR-0012 is overridable if option A demonstrably improves accuracy. **The pass ran 2026-08-20 and all three bars passed** (0/84 state flips; 1/51 GT miss per run, state-irrelevant on inspection; 42/42 controls; 50/59 marginal yield; 0/25 danger-class contradictions). Per the frozen verdict rule, **A-prime enters v1**: a post-read attribution pass (the model maps each finding of a read to hunk numbers of its cited file's sent diff; code validates the numbers, converts them to hunk hashes, and stores them on the finding) refines rule 5 for `unknown(not-reconfirmed)` candidates — every attributed hunk survives → `persisted(basis=attributed-surviving)`; none survives and the later read is silent → `resolved(basis=attributed-edited)`; mixed, invalid, absent, or abstained → `unknown(not-reconfirmed)` unchanged. `classify` stays pure — attribution rows are inputs; the model call happens at read time, never at classify time. Reader SCHEMA and PROMPT_HASH untouched; ADR-0012 stays closed; ADR-0014 records the attribution pass; generative spans (option A as drawn) move to ADR-0015+ and stay vNext. Rulings 2 and 3 (2026-08-20): the per-PR count stays in v1; the reland-labeler gate does not apply to the silence rate.
- **Bar A(B) FAILED at Phase 0 (2026-08-20, [phase0-results.md](phase0-results.md)):** 4/6 `resolved(hunk-edited)` and 2/5 `resolved(attributed-edited)` sample units are false — a byte-change in a hunk is not evidence the defect in it was addressed (comment-only edits, adjacent-line edits, and new-file single hunks all re-hash without touching the defect). The carry-forward direction stands validated (0/4 false attributed-surviving; all five original false-`resolved` disasters correctly carried). **This lock's `resolved` states do not ship as designed.** Pending Andrew's ruling: demote both edit-based `resolved` states to `unknown(edited-not-verified)` in v1 and pre-register a verify-at-resolve adversarial check for v1.1 (recommended), or an alternative he names.

## Warranted mitigations applied

- **Scope:** `left-diff` → `unknown` unconditionally (collapses A1–A3); `disproved`, `halt_guidance`, and the payload addendum deferred to v1.1; `evidence` field dropped (the eval labels its own JSON); `_verdict_bundle` narrowing dropped; prior-side rule 3 derived from the index with absent ≠ `[]`.
- **Honesty:** the by-construction sentence is "cited file's diff is byte-unchanged since <sha12>; carried forward, not re-verified" — never "the defect cannot have moved"; `resolved`/`closed` means "Doug stops carrying it", never a verified fix; Bar A(B) at n=6 licenses only "0 of 6 retrospective units false; self-labelled; emulated" (CP95 upper ≈0.39 reported; the sample's seventh option-B `resolved` unit, #67 `web/package-lock.json`, is `unknown(left-diff)` under this lock, so the 43-unit split is 6 resolved / 26 by-construction / 11 unknown); the silence rate's honest denominator is earlier findings on unchanged files (population 160/213 = 75%), not 160/265; `report.ratio` never rides a frozen payload (counts only); the provenance line drops "N pushes ago" (Doug cannot count pushes it did not see); the emulation's two assumptions are stated in the label; every document says "Doug's deterministic index does not know which hunk a finding is about; the attribution is model output, validated against the sent hunks and stored, never re-derived at classify time"; v1.1 `nothing-open` requires every `unknown` reason to count as unconfirmed and the later read's coverage to be complete, and is named `nothing-carried`.
- **Altitude:** the silence count is the section's headline; the silence-rate pre-registration is written now as a sibling in `convergence-design.md` (it contains no defect labels — whether the reland-labeler gate applies is Andrew's call); `hunk_index` is a library function with the eval as one caller so the same definition can grade other reviewers' resolve claims on public repos; copy says "stricter and reproducible", never "finer than GitHub's `outdated`"; the provenance line names whose claim is graded.

**Judged noise, left unmitigated:** cutting `pair_delta` from v1 (the honesty red team requires its sentence; it is one boolean); cutting `code_changed` on `new` (it is the line that grades the reader in the other direction and costs one lookup; no guidance consumer in v1); posting findings as review threads to use GitHub's `outdated` (makes Doug a reviewer in the thread, impossible at line grain without A, not replayable offline); the eval's per-side-base emulation (it moves nothing on the sample and is what ships).

## Non-goals / do-not-reopen

- No model-emitted spans, no `SCHEMA`/`PROMPT_HASH` change, no paid citations in v1. ADR-0012 stays closed; a future span ADR is ADR-0014 or later.
- No compare API, no clone, no network in the classification path; the certificate replays from rows.
- No stored certificate or cached counts; `convergence_for` recomputes.
- No importer of `convergence` other than `store.py`; nothing in `score()`; no ratio, rate, or halt verb on the check run in v1; conclusion `neutral`.
- No new wire/API/web field in v1 (zero consumers); `Reason.file` stays off-wire.
- No suppression of `new` findings on unchanged code (four learning-loop rulings: provable deletes only); no evidence flows back into the prompt.
- Bar 1 stays FAILED; the 2026-08-11 sampling plan is immutable; Bar A(B)/Bar B are new bars on the same sample; bar 2 PASS; bar 3 NO EVIDENCE; rules 2–4 and their order survive.
- Prereg v9 LOCKED; the governor (skip a re-read) stays shadow-only and is a prospective v10 if it ever ships; the stuck-loop alarm waits for an autonomous loop with ground truth.
- The reland-labeler fix is backlogged and out of scope; it gates any defect-labelled publication, not the certificate.
- Publish the cleared-band miss rate alone; the silence rate beside it is self-disclosure, never a comparator.
