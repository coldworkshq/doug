## Rulings

R1. **Span mechanism: option B in v1** — identity = (pattern, file, multiset of content-hashes of the hunks of that file in the SENT patch). Hash = sha256 over the `+`/`-` lines of each unified hunk only (no `@@` numbers, no context). Model-emitted spans (A) are a measured upgrade, not v1: trigger = prospective abstention rate published after ≥N pairs AND a pre-registered span-validation design (cite()-style check against sent hunks) AND ADR-0013. Paid citations (C) stay out. **Killed:** A in v1 (PROMPT_HASH re-anchor, pin-test split, unvalidatable on history, a hallucinated span is a silent false `persisted` — worse than an abstention in a loop). **Why:** 74% of the population gets an evidence-backed state under B today; 100% gets an unevidenced `resolved` today. B's index is A's validator, so nothing is wasted. **Cost:** B abstains on 67% of touched findings; `resolved` is rare. **Note for Andrew:** this honors ruling 1 (hunk identity now) in substance — identity is hunk-hashed — but not in letter ("findings must carry line/hunk spans"): B is file-delta identity at hunk grain, not a per-finding span. Andrew confirms or overrides.

R2. **`persisted-by-construction` is split by pair delta.** Report carries `pair_delta ∈ {unchanged, changed-elsewhere}` computed from the two hunk indexes (any file's multiset differs). Both are `persisted` for the ratio and `open` for guidance; the human sentence differs ("cited code unchanged since <sha>" vs "cited code unchanged since <sha>; other code in this PR changed — if you addressed it elsewhere, a human should look"). **Killed:** treating changed-elsewhere as unconfirmed (would hand the majority case — real still-present findings the reader dropped, 26/43 — to a human). **Why:** Bar B measures exactly this bet; the #75 fix-elsewhere class is the pre-declared ≤1/26. **Cost:** a named false-persisted class (fix landed in another file) exists in v1; the v1.1 guidance carries a loop-breaker (R7).

R3. **Settle → `disproved`, its own terminal state**, never in the ratio, `closed` for guidance. Rule 4 keeps its position and its abstention-from-`resolved` meaning; its output is renamed by amendment-log entry; bar 3 remains NO EVIDENCE (n=0). **Killed:** fold into `resolved` (changes what bar 3 and the ratio mean); keep `unknown(settled)` (misroutes an agent to a human for a finding Doug itself disproved).

R4. **Persistence: `reads.hunks` JSON column (migration 12, additive), not a new table.** `_verdict_bundle`'s `select(reads)` is narrowed so idempotency/replay reads don't drag the JSON. **Killed:** `read_files` table (no per-file query exists). No hunk data in `findings` or `verdicts.raw`; no coverage flag in the index (coverage stays in `reads.files_unseen/file_cut/files_dropped`, one representation).

R5. **Importer: `store.py` only**, via `store.convergence_for(verdict_id)`: id-keyed; prior = latest reader-tier verdict with `id < verdict_id` for the same (installation, repo, pr); loads both sides' findings + reads; calls the pure `classify`; wrapped try/except → weight-0 notice so a DB hiccup after a paid read cannot kill the job or the check run. Worker calls it after `save_review` and in `_replay_recorded`; the importer test is amended to allow exactly `store.py`, as it pre-declared. **Killed:** worker importer (silent reversal of a recorded test intent).

R6. **Hunk-set semantics (rule 5 replacement), per prior identity absent from the later read and not abstained by rules 2–4:**
   - prior multiset == later multiset → `persisted(by-construction)` (+ R2 pair_delta)
   - all prior hashes absent, file present in later patch with ≥1 hunk → `resolved(basis=hunk-edited)`
   - all prior hashes absent, file absent from later patch and not named in later `files_unseen/file_cut/files_dropped` → `resolved(basis=left-diff)` (file reverted to base, or hunks absorbed into base) — human sentence "no longer in this PR's diff"; **named error class:** base absorption on rebased/stacked PRs can read as left-diff/hunk-edited while the code lives in main (3/76 pairs). `base_moved` (from `review_jobs.base_sha` on both jobs) rides the report for the provenance line; not an abstention.
   - some prior hashes survive (with or without extras), or prior ⊂ later → `unknown(not-reconfirmed)` (strict equality for by-construction: an added hunk in the same file may be the fix attempt)
   - either side lacks a hunk index (pre-migration row, old revision) → `unknown(no-hunk-index)`
   - file uncovered in the PRIOR read → `unknown(file-uncovered)` (rule 3 extended to the prior side)
   - `new` findings carry `code_changed: bool` from the same indexes; rendered as "New (N)" and "New on code unchanged since <sha> (M)"; never suppressed (ruling 4: provable deletes only).
   Report carries `evidence ∈ {hunk, hunk-emulated, file}` set by the caller.

R7. **Guidance (v1.1 contract, frozen now, pure function `halt_guidance(report)`):** open = persisted(any basis) ∪ new; closed = resolved ∪ disproved; unconfirmed = unknown(not-reconfirmed | no-hunk-index). `keep-going` if any open; `nothing-open` if no open and no unconfirmed; `hand-to-human` if no open and any unconfirmed, OR the loop-breaker: a by-construction finding with pair_delta=changed-elsewhere survives K consecutive pairs (K pre-registered, default 3). Treatment of `new` on unchanged code is an **open risk** for v1.1 (default: open, conservative). `nothing-open` is rare by construction (new=0 in 7% of pairs) — the spec says so.

R8. **Evaluation emulates the product's function.** The eval script computes hunk hashes per side as `git diff $(git merge-base origin/main <head>) <head> -- <file>` (declared approximation of the PR's three-dot base at read time) and applies R6; file-grain `git diff --name-only from to` is reported beside it as the proxy it is. Evidence label `hunk-emulated`. Bars re-pre-registered for B in `convergence-design.md` before any labelling: **Bar A(B):** zero false among the B-`resolved` units in the seeded 43-unit sample (n≈7; 0.90 point estimate permits none at that n — said out loud; CP interval reported, never gates); **Bar B:** false-`persisted` ≤1/26 among by-construction units, #75 deploy-ordering pre-declared; **reported, not gated:** abstention rate (sample 10/17 touched; population 70/105), recall price, flip-rate floor (160/265 file grain; B-emulated figure beside it), `new`-on-unchanged-code rate. Governor stays shadow-only as in IDEAS. Labels: Andrew's, ~26 new units.

R9. **Check run v1:** one `### Since <sha12>` section in the summary under a provenance line ("Compared with Doug's last diff read at <sha12> — N pushes ago; pushes in between were not read; base moved: yes/no"); headings in PM's order with PM's words except: hunk-edited = "Cited code changed, not reported again" (never "gone"/"fixed"/"verified"); left-diff = "No longer in this PR's diff"; disproved = "Disproved" (inline, no empty heading); Can't-say lines name the reason in plain words; per-PR count sentence with denominator ("of N prior findings on unchanged code, M were not mentioned by this read"); no ratio, no rate, no annotations, no `details_url` change, no banned words. Conclusion stays `neutral`.

R10. **Wire/receipt/MCP:** no API/web change in v1 (zero consumers). Payload shape (states, basis, reasons, pair_delta, code_changed, evidence, base_moved, guidance) is frozen now by a dated addendum to the Lane-2 plan (Task 4 `ReceiptConvergence`, Phase 2 `get_convergence`) so v1.1 renames nothing. Flip RATE only on the scoreboard after the reland fix AND a pre-registered definition (v10 disclosure or sibling prereg), web-validator-first; ADR-0005 sentence form.

R11. **v1.1 trigger (guidance string live):** ≥10 prospective `resolved` units with a hunk index on both sides, hand-checked, zero false; plus a Bar-B-style false-persisted sample. **Supersedes** PM's "20 pairs, zero false Gone" (vacuous at B's resolve rate).
